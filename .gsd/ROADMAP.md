# Standalone migration roadmap

1. Shared domain and local service: extract core, define task contracts, persistence and discovery.
2. Bot execution: scheduled monitoring, cancellation, persistent visible browser and seat-selection handoff.
3. Dashboard: responsive task controls, live activity, results, seat map, settings and history.
4. Integrate and verify: build/start scripts, unit/API/browser tests, screenshots and operator documentation.

Implementation follows these phases sequentially. Project requests already authorize the migration and local operation.
